# Simulated Dust Blueprint for CARLA

A simple UE4 blueprint for LiDAR-perceivable dust simulation in CARLA.

## Requirements

- CARLA 0.9.12
- Unreal Engine 4.26

## Files

- `Dust_BP_oa.uasset`: Main dust simulation blueprint asset.

## Usage

Place the `.uasset` file into your CARLA UE4 project `Content` directory and reopen the project.
